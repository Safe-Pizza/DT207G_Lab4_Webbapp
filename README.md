# Laboration 4 Uppgift 2, DT207G Autentisering och säkerhet
Detta är en laboration i _Webbutveckingsprogrammet_ på Mittuniveristetet.

## Redovsning
[Webbplats](https://safe-pizza.github.io/DT207G_Lab4_Webbapp/)

## Syfte
Syftet med denna laboration använda Fetch API för att konsumera webbtjänsten för lagring och inloggning av användare skapad i uppgift 1 för Laboration 4.

## Uppgift
Du ska skapa en webbapplikation som använder FetchAPI. Applikationen ska konsumera webbtjänsten från uppgift 1 och bestå av nedan undersidor:

* **index.html:** Startsida med information om sidan,
* **login.html:** Formulär för att logga in användare i webbtjänsten och formulär för att registrera ny användare,
* **admin.html:** Adminsida vid inloggad användare, listar alla användare och knapp för att ta bort användare.

## Lösning
Här kan du läsa om vilka funktioner som finns för lösningen av denna laboration: 

### Funktioner
* **Logga in användare:** Användare kan logga in via login-sida,
* **Registrera användare:** Användare kan registreras i webbtjänsten,
* **Lista användare:** Användare som finns listas på adminsidan i inloggat läge,
* **Ta bort användare:** Anvädare kan tas bort via knapp på adminsidan i inloggat läge,
* **Validering:** Inputfälten valideras, fälten får ej vara tomma och vid registrering måste båda lösenordsfälten överrensstämma.
